## Project 1: REST API Testing with Postman

**Application:** QA Auto (educational testing application)

**Tools:** Postman, REST API, JSON, JavaScript

This project contains a Postman collection with 8 API requests covering:

1. User registration
2. User profile update
3. Distance unit settings
4. Car creation
5. Car mileage update
6. Fuel expense creation
7. Car deletion
8. User deletion

### Testing Techniques

- HTTP status code validation
- JSON response field validation
- Dynamic collection variables for user and car IDs
- Randomized email generation for test data
- Pre-request scripting for date generation
- Automated response assertions using Postman scripts
